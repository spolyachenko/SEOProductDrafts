# AI-помощник для подготовки товарных описаний

По входным данным о контрольно-измерительном приборе (в формате JSON) создаёт
черновик карточки товара через LLM: SEO-заголовок, SEO-описание, ключевые характеристики, 3–5 поисковых запросов и
коммерческий блок.

## Установка

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

cp .env.example .env
# Заполните .env файл корректными данными
```

## Прогон по примерам

Скрипт обработает товары в examples.json асинхронно.

```bash
.venv/bin/python main.py
```

Пример вывода:

```
OK   Счетчик импульсов ОВЕН СИ8-Щ2.Р -> results/счетчик_импульсов_овен_си8_щ2_р.json
OK   Термоанемометр DT-8880 -> results/термоанемометр_dt_8880.json
OK   Преобразователь аналоговых сигналов ОВЕН НПТ-3.00.1.2 -> results/преобразователь_аналоговых_сигналов_овен.json
```

При отклонении модели (выдуманное число / нарушение схемы) в тот же файл
записывается `{"name": …, "error": …}` — остальные батч не прерывается.

## Запуск сервера

```bash
.venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000
```

Один эндпоинт: `POST /generate`. Тело запроса — JSON по схеме `ProductIn`

Для проверки эндпоинта можно перейти на `localhost:8000/docs` или 

```bash
curl -s localhost:8000/generate \
  -H 'content-type: application/json' \
  -d '{
    "name": "Термоанемометр DT-8880",
    "manufacturer": "CEM",
    "specs": {
      "Диапазон измерений температуры, °С": "от 0 до +50",
      "Диапазон измерений скорости воздушного потока, м/с": "от 0,1 до 25"
    },
    "description": "Компактное цифровое устройство для замера скоростей воздушных потоков; двойной дисплей, телескопический щуп, USB."
  }'
```

Коды ответов: `200` — карточка; `422` — некорректный JSON / пустые обязательные
поля; `502` — модель нарушила схему или ввела число, которого нет во входных
данных (grounding-проверка); `503` — LLM недоступна (после внутренних ретраев).

## Тесты

```bash
.venv/bin/python -m pytest -q
```

- `test_generate` — все 3 товара одним параллельным батчем, ожидает `200`
- `test_invalid_body` / `test_malformed_json` — `422` на мусорных телах
